## Generating Icons

You can use tools like:
- [PWA Asset Generator](https://github.com/nickvdyck/pwa-asset-generator)
- [Real Favicon Generator](https://realfavicongenerator.net/)
- [Maskable.app](https://maskable.app/) for maskable icons

## Design Guidelines

- Use the AgriFinance brand colors:
  - Primary: #166534 (Deep Forest Green)
  - Accent: #d97706 (Warm Gold)
  - Background: #f8fafc (Light Gray)

- For maskable icons, ensure the main content is within the safe zone (center 80%)
- Use a simple, recognizable symbol (e.g., leaf, plant, or farm icon)
